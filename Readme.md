> Um sistema pessoal de organização de tarefas, projetos, aulas e cursos, desenvolvido passo a passo para aprender desenvolvimento web e backend.



\## Sobre o projeto



O Meu Kanban Pessoal é um projeto full stack em construção.



A primeira versão permitirá organizar tarefas nas colunas:



\- Não iniciados

\- Em andamento

\- Concluído



O objetivo principal é aprender os fundamentos de desenvolvimento enquanto construo uma aplicação real, desde a interface até o banco de dados e a publicação online.
